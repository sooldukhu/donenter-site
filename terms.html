1. 서비스

"흑백리뷰 총관"(이하 "서비스")은 (주)돈엔터테인먼트가 흑백리뷰 채널의 콘텐츠 기획, 성과 분석, 운영 업무를 위해 내부적으로 사용하는 도구입니다. 일반에 판매하거나 제공하는 서비스가 아닙니다.

2. 이용 대상

서비스는 회사가 승인한 구성원만 이용할 수 있으며, 회사가 소유·관리하는 채널과 계정에 대해서만 사용합니다.

3. 이용자의 의무

이용자는 YouTube 서비스 약관과 Google API 서비스 약관을 준수해야 하며, 서비스를 통해 얻은 데이터를 업무 목적 외로 사용하지 않습니다.

4. 책임의 한계

서비스는 외부 플랫폼이 제공하는 데이터를 바탕으로 동작하며, 해당 플랫폼의 정책 변경이나 장애로 인한 데이터 지연·누락에 대해 책임지지 않습니다.
