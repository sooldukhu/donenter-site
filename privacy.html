개인정보처리방침

시행일: 2026년 10월 21일 · (주)돈엔터테인먼트

(주)돈엔터테인먼트(이하 "회사")는 흑백리뷰 채널 운영을 위한 내부 도구 "흑백리뷰 총관"(이하 "서비스")을 운영합니다. 이 방침은 서비스가 Google 계정을 통해 접근하는 정보를 어떻게 다루는지 설명합니다.

1. 접근하는 정보

  • 회사가 소유·관리하는 흑백리뷰 YouTube 채널의 영상 목록, 제목, 설명, 태그, 공개 통계(YouTube Data API, 읽기 전용)
  • 같은 채널의 분석 데이터: 조회수, 시청 시간, 구독자 증감, 예상 수익 등(YouTube Analytics API·Reporting API, 읽기 전용)

서비스는 채널 운영자 본인의 Google 계정 승인으로만 동작하며, 외부 이용자의 개인정보를 수집하지 않습니다.

2. 이용 목적

채널 성과 분석, 일일·주간 실적 보고서 작성, 콘텐츠 기획 참고 자료 정리에만 사용합니다.

3. 보관과 보호

데이터는 회사가 관리하는 업무용 컴퓨터와 회사 Google Drive에 저장하며, 인증 정보는 운영자만 접근할 수 있는 위치에 보관합니다.

4. 제3자 제공

Google API를 통해 받은 정보를 제3자에게 판매하거나 제공하지 않으며, 광고 목적으로 사용하지 않습니다. 서비스의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

5. 보관 기간과 삭제

채널 운영에 필요한 기간 동안 보관하며, 목적이 끝나면 지체 없이 삭제합니다. 언제든 Google 계정 권한 설정에서 서비스의 접근 권한을 철회할 수 있습니다.
